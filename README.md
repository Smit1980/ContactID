# ContactID

Личная контактная страница Дениса Шандалина для знакомства на конференции. Публикация: https://smit1980.github.io/ContactID/

Сделано как статический сайт без внешних зависимостей. `index.html` — содержимое; `styles.css` — стиль презентации и мобильная адаптация; `app.js` — ссылки с черновиком сообщения и окно QR. Портрет и шрифты взяты из локальной презентации.

Посетитель вводит имя, выбирает Telegram, MAX, WhatsApp или почту. В Telegram, WhatsApp и почте черновик создаётся через ссылку; в MAX приветствие копируется перед открытием личного чата, потому что публичная ссылка на профиль не поддерживает адресованный черновик. Ничего не отправляется автоматически.

WhatsApp включается только после подтверждения номера владельцем: укажите международный номер цифрами в `WHATSAPP_NUMBER` в `app.js`, затем опубликуйте изменение.

QR-код в `assets/contact-qr.svg` содержит адрес страницы. Если адрес публикации меняется, обновите `PAGE_URL` в `app.js` и пересоздайте QR.
